# Psy_sis_algo — Алгоритмическая оболочка БО840

Граф знаний библиотеки БО840 в машиночитаемом формате JSON.

## Состав

| Файл | Назначение |
|---|---|
| `graph.json` | Граф всех сущностей (узлы + индексы) |
| `bo840_parser.py` | Парсер markdown → JSON (для обновлений) |

## Структура graph.json

```json
{
  "nodes": { "ловушка_экзаменатор": { "type": "trap", ... }, ... },
  "cases": { "case_001": { "patterns_detected": [...], ... } },
  "index": { "by_tag": {...}, "by_type": {...}, "by_file": {...} }
}
